1. ERRO 404 NA URL RAIZ
------------------------
Sintoma:
Ao acessar http://127.0.0.1:8000/, o Django exibia "Page not found (404)".

Causa:
O arquivo todoapi/urls.py possuia apenas as rotas /admin/, /api/login/ e /api/.
Nao havia uma rota para o caminho vazio (/).

Correcao:
Foi criada a funcao home em todoapi/views.py, retornando um JSON de status:
{
    "projeto": "API de Tarefas",
    "status": "online",
    "mensagem": "API funcionando. Consulte /api/login/ e /api/tarefas/."
}
A rota vazia foi adicionada em todoapi/urls.py.

Validacao:
GET / retornou HTTP 200.
GET /api/tarefas/ sem token continuou retornando HTTP 401.

2. ERRO NO TESTE DA ROTA RAIZ
-----------------------------
Sintoma:
O teste test_home_funciona falhou com:
AttributeError: 'JsonResponse' object has no attribute 'data'

Causa:
response.data e uma propriedade usada nas respostas do Django REST Framework.
A rota raiz usa JsonResponse do Django, que fornece o metodo response.json().

Correcao:
O teste foi alterado para verificar:
response.json()['status']

Validacao:
O conjunto de testes passou com 9 testes aprovados.
